# CT80A0000-Data-Intensive-Systems-T2-Database-App
Database management app for a CT80A0000 Data-Intensive Systems coursework assignment

run the app with:

python -m streamlit run app.py

App should open in a browser.


Python and Streamlit must be installed.

Install Streamlit: pip install streamlit


The app is developed with Python, SQLite and Streamlit
